## Core idea

Every customer experience creates information about a business, but only part of that information becomes public and remains available to future buyers.

Compounding Public Evidence provides a framework for analysing how important real properties of a business are represented in this accumulated public layer:

- what is publicly evidenced;
- how strongly it is evidenced;
- where it is accessible;
- where Public Evidence Gaps exist;
- how the evidence structure changes over time.

The framework centres on the relationship between:

**Operational Reality → Reference Attribute Inventory → Choice Relevance → Public Evidence Structure → Coverage / Strength / Gaps / Surface Distribution → Public Evidence Dynamics**
